🛡️ Cybersecurity Labs & Writeups
A centralized repository documenting my hands-on practice, writeups, and investigations across both Offensive (Red Team) and Defensive (Blue Team) security.

📌 Overview
This repository serves as a comprehensive knowledge base of real-world attack simulations, threat hunting, and incident response performed in controlled environments.

The focus is on:

Practical exploitation & defense

Methodology development

Consistent documentation of findings

🗂️ Repository Structure
This repository is split into two main directories:

📁 Offsec-Machines/ – Penetration testing, boot-to-root machines, web exploitation, and CTF challenges.

📁 SOC-Machines/ – Blue team investigations, log analysis, threat hunting, and incident response.

(Detailed breakdowns of the platforms and methodologies used for each section can be found in the README.md files inside their respective folders).

⚔️ Platforms Covered
Offensive: Hack The Box (HTB), TryHackMe (THM), VulnHub, PicoCTF

Defensive: TryHackMe (SOC Paths), CyberDefenders, LetsDefend

📊 Focus Areas
Offensive: Web App Security, Privilege Escalation, Network Pentesting, CTF Problem Solving.

Defensive: SIEM (Splunk), Log Analysis, Threat Hunting, Malware Analysis, Incident Response.

 Disclaimer
All content in this repository is intended for educational purposes only. Activities are performed on authorized platforms and intentionally vulnerable systems, or systems I have explicit permission to test.
